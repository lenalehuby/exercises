# MSc Exercises

Consolidated archive of the coursework exercises and projects from my MSc. Each folder below was previously a standalone GitHub repository under [lenalehuby](https://github.com/lenalehuby); the contents were copied here as-is (without git history). See [NOTES.md](NOTES.md) for files that were left out because of size.

| Folder | Description | Main tools |
|---|---|---|
| [ai-classifiers](ai-classifiers/) | A hands-on exploration of core AI classification algorithms, KNN, K-means, Naïve Bayes, and hierarchical clustering, applied to 2D data and handwritten digit recognition using Python notebooks. | Python, Jupyter, tkinter (from-scratch implementations) |
| [swarm-algorithms](swarm-algorithms/) | Simulations of classic flocking and swarm intelligence algorithms, including boids, gravity boids, obstacle avoidance, and swarm-based optimization, in Python notebooks with interactive visualizations. | Python, Jupyter, tkinter |
| [expert-systems-algorithm](expert-systems-algorithm/) | A collection of interactive Python notebooks demonstrating core expert system algorithms, from 20-questions-style games to rule-based logic and property elimination. Includes simple inference engines, animal identification, and explanation tracing, easily adaptable to other decision or diagnostic tasks. | Python, Jupyter (pure-Python rule engines) |
| [neural-networks-digit-recognition](neural-networks-digit-recognition/) | From-scratch neural network notebooks for reliable handwritten digit classification. Includes feed-forward and backprop implementations, network topology experiments, and real-world banking form scenarios. Designed for hands-on learning and adaptable to many classification tasks. | Python, Jupyter, tkinter, TensorFlow/Keras, scikit-learn |
| [data-augmentation-pipeline](data-augmentation-pipeline/) | A Python toolkit and notebook series for practical data augmentation, handling missing values, expanding text, and enriching time-series data for ML pipelines. Features sampling, statistical modeling, and visualization with Pandas, Matplotlib, SciPy, and NLTK. | Pandas, SciPy, NLTK, Matplotlib |
| [brain-tumor-mri-classification](brain-tumor-mri-classification/) | End-to-end pipeline for brain tumor MRI classification using Vision Transformers. Includes image preprocessing, simulation, model training, and evaluation with Hugging Face, PyTorch, and Colab GPU support. | Hugging Face Transformers (ViT), PyTorch, HF Datasets, TensorFlow/Keras, phantominator, Google Colab |
| [mri-segmentation-transformers](mri-segmentation-transformers/) | End-to-end pipelines for brain MRI tumor segmentation using transformer models (SegFormer and MaskFormer). Includes dataset exploration, custom accuracy metrics, model training, and performance benchmarking on real medical data. | Hugging Face Transformers (SegFormer, MaskFormer), PyTorch, HF Datasets, Albumentations, OpenCV |
| [construction-site-object-detection-transformers](construction-site-object-detection-transformers/) | Object detection pipeline for construction site surveillance using transformer models and Roboflow datasets. Covers vehicle tracking and building defect identification with DETR-family models, dataset creation, augmentation, and benchmarking. | Hugging Face Transformers (DETR family), PyTorch, Roboflow, Albumentations, HF Datasets |
| [transformers-deployment-explainability](transformers-deployment-explainability/) | Deploying the brain-MRI classification and segmentation transformer models as a Gradio web app, and explaining construction-vehicle detector decisions with Grad-CAM and LIME visual overlays.¹ | Gradio, Hugging Face Transformers, PyTorch, pytorch-grad-cam, LIME |
| [Synthetic-Data-Generation-Deployment-for-Object-Detection](Synthetic-Data-Generation-Deployment-for-Object-Detection/) | Project from NVIDIA training - NVIDIA DLI Hands-On Pipeline | NVIDIA Omniverse / Isaac Sim Replicator, PyTorch, torchvision, Triton Inference Server |
| [Synthetic-Data-Generation-for-Perception](Synthetic-Data-Generation-for-Perception/) | Generating annotated synthetic warehouse scenes (RGB, depth, and pixel-wise semantic masks) for object detection and segmentation with NVIDIA Isaac Sim Replicator, then training with TAO Toolkit. Based on NVIDIA DLI course S-OV-30.¹ | NVIDIA Isaac Sim, Replicator, TAO Toolkit, OpenCV, Jupyter |
| [Omniverse-cosmos-synthetic-data-workshop](Omniverse-cosmos-synthetic-data-workshop/) | Notebook workflow for generating synthetic training data via NVIDIA Omniverse & Cosmos, build digital twins, simulate sensors, engineer prompts, and automate realistic data creation for factory Physical AI. | NVIDIA Omniverse, NVIDIA Cosmos, Jupyter |
| [warehouse-rl-project](warehouse-rl-project/) | Reinforcement learning experiments for warehouse automation using OpenAI Gym, Q-learning, and deep RL. Features robotic cart navigation, custom grid-worlds, deep RL stability methods, and milestone-by-milestone insights, in Python notebooks. | OpenAI Gym, PyTorch, Q-learning / deep RL |
| [Multimodal-Sentiment-Analysis](Multimodal-Sentiment-Analysis/) | NLP and Computer Vision Multi-Modal Sentiment Analysis Project | PyTorch, torchvision (ResNet-50), Hugging Face Transformers (BERT), Pandas |
| [Counterfeit-Drug-Detection](Counterfeit-Drug-Detection/) | Computer-vision system that flags counterfeit medications from packaging and pill images using EfficientNetB0 transfer learning, with synthetic counterfeit generation and a Gradio web interface.¹ | TensorFlow/Keras (EfficientNetB0), OpenCV, scikit-learn, Gradio |
| [Smart-Home-Automation](Smart-Home-Automation/) | This project implements a simple smart home application that allows users to control and monitor various devices (lights, fans, and thermostats) using natural language commands processed by a Hugging Face Transformers model. | Python, Hugging Face Transformers (zero-shot classification) |

¹ The original repository had no GitHub description; this summary was written from its README.

## Layout

Every folder keeps the original repository's own README, notebooks, and source files. Three projects (Counterfeit-Drug-Detection, Omniverse-cosmos-synthetic-data-workshop, Smart-Home-Automation) carry their own LICENSE file, which continues to apply to that folder.
